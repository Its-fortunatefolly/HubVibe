Example bundle call:

curl -X POST https://hubvibe-831480473793.us-south1.run.app/audit/bundle \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <signed x402 payment header>" \
  -d '{"url": "https://example.com"}'

No payment header, or an invalid one, returns HTTP 402 with the exact price and payment details — construct it with an x402 or MPP client library, not by hand. A subscriber's X-API-Key works here too.
