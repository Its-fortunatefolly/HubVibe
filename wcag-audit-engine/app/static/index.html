Example: a $0.10 x402 call to the full bundle —

curl -X POST https://hubvibe-831480473793.us-south1.run.app/audit/bundle \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <signed x402 payment header>" \
  -d '{"url": "https://example.com"}'

No X-PAYMENT header, or an invalid one? You get back HTTP 402 with the exact price, network, and payment address needed — construct the header with an x402 client library (or MPP, see the agent manifest), not by hand. A Stripe X-API-Key works here too if you'd rather bill an agent's calls to a human account.
